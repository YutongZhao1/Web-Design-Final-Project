This website is a student guide designed to help incoming and current NYU students make the most of their time in New York City. The site is organized into five pages: a home page with an introduction and a NYC skyline photo, a food page highlighting must-try restaurants and food trucks in the city, a places page covering iconic NYC attractions and entertainment venues, a school resources page detailing essential campus facilities, and a community page where students can submit their favorite NYC memories and discover fun facts about the city. Each page features a consistent fixed navigation bar at the top, card-based layouts with photographs and descriptions, and a purple-and-gold color scheme inspired by NYU's signature violet. The design prioritizes clarity and visual appeal, using CSS Grid for multi-column layouts on desktop and a single-column layout on mobile devices.
